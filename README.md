## Sobre o Projeto
Este projeto é um sistema web desenvolvido focado na aplicação prática de HTML5 e CSS3. O projeto contem tabelas e formulários, âncoras e navegação estruturada.

## Tecnologias Utilizadas
* **Front-end:** HTML5, CSS.
* **Servidor Local:** Apache (XAMPP).

## Como Rodar o Projeto

### Pré-requisitos
* Ter o [XAMPP](https://www.apachefriends.org/).

### Passo a Passo
1.  **Clone o repositório** na sua pasta `htdocs`:
    ```bash
    git clone https://github.com/CJSabino/web-frontend-fundamentals.git
    ```
    
2.  **Inicie o Servidor:**
    * Abra o XAMPP e inicie **Apache**.
    * Acesse no navegador: `http://localhost/suapasta/home.php`
